# 官方 Codex 用量统计修复

本修复随 v0.1.52 发布。下文美元单价为旧版参考记录口径；当前界面统一使用元衡平台闪电估算，详见 [平台报价同步说明](2026-09-11-yuanheng-pricing-sync-plan.md)。

## 原因与实测

通过已配置的本机官方代理，发送一次只回复 OK 的最小请求：HTTP 200，没有 `Content-Type`、没有 `Content-Encoding`，实际响应体是 SSE。末尾 `response.completed.response.usage` 明确包含输入 20、输出 5。

旧 `process_response` 只凭响应头判断 SSE，因而整包缓存并按普通 JSON 解析。JSON 解析失败后，记录默认零 Token、非流式请求；零值表示没有解析到用量，不能解释成真实零消耗。

## 修改

- 对成功且未声明类型、未压缩的响应，探测最多 256 字节、32 个块；识别 SSE 标准字段后补充响应类型。按原顺序重放所有字节，不等待整段生成完成。
- 保留明确的内容类型、错误响应，以及用户配置的流式/非流式超时；超时关闭时不另设硬超时。
- 收尾解析缺少最终空行但 JSON 完整的 SSE 用量事件，不猜测截断 JSON。
- 无有效用量的旧回退记录显示未知，不能显示成免费零消耗。已有上游响应 ID 的明确零用量保留零值。
- 已确认通过 `codex-official` 代理的请求显示“账号计费”，不把本地 API 单价估算冒充官方账号实际扣费。总金额标为“参考成本”，说明未定价用量不包含在金额中。
- `Codex (Session)` 来自本机 Codex 会话日志导入，并非额外供应商或额外发送的请求。导入器没有保存每次真实上游路由，历史会话的 provider 标识也可能在切换登录方式后被复用，因此保留未确认归属并明确显示来源；不按当前配置重写历史供应商。
- 会话导入缺少真实 HTTP 状态和耗时时显示未提供，避免伪造 HTTP 200 和 0 秒响应。

## 价格与历史数据

原内置表遗漏了 `gpt-6-astra`。已于 2026-09-11 核验并补入 [OpenAI 官方 Standard 参考价](https://developers.openai.com/api/docs/models/gpt-6-astra)：每百万 Token 输入 $10、缓存读取 $1、缓存写入 $12.50、输出 $50。单次完整输入（含缓存）超过 272,000 时，整次请求改用 $20 / $2 / $25 / $75 的长上下文费率。

实时代理记账、Codex 会话导入和历史缺价回算使用同一阶梯规则。该规则仅对完整匹配内置 Standard 价格的条目生效，已自定义的价格不覆盖，也不按名字推断 Fast、Batch 等处理模式。实际账单可能包含这些模式、折扣或地区差异；界面始终将金额标为参考成本。

`codex-auto-review` 未核实到独立公开报价，保留未知，不套用 Astra 单价。已确认的官方账号请求显示“账号计费”，有参考值时额外展示 API 参考成本。

[OpenAI 认证说明](https://developers.openai.com/codex/auth/) 区分 ChatGPT 账号的订阅访问和 API Key 的按量访问。

没有 Token 的旧代理行无法补填。已有真实 Token 且缺少费用的记录可按当前参考价回算；已存在的金额保留。不会修改 Token 数、供应商归属、登录凭据或对话内容。

## 验证

- 缺失响应类型的碎片化 SSE，经探测、原字节转发、事件解析、SQLite 写入后，官方供应商输入 20、输出 5，标为流式。
- 覆盖没有最后空行、keepalive 前缀、不等待流结束、JSON/错误/明确类型保留、超时和空块边界。
- 覆盖未知用量、明确零用量、全缓存输入、账号计费、会话导入与未定价、真实已定价 API 请求。
- 本机最小真实请求仅用于确认上游响应结构；回归测试使用合成数据，不调用模型或真实账号。

验证结果：13 项响应处理回归通过，769 项前端测试通过，TypeScript 类型检查及 Rust Clippy（禁止警告）通过。

新增价格回归覆盖 272K 边界、缓存计入上下文、长价作用于整次请求、缓存写入、倍率、自定义价保护、别名查价和历史回算。示例：新输入 1,074、缓存读取 224,256、输出 94 的 Standard 参考成本为 $0.239696。

补价验证：31 项用量统计测试、43 项代理用量测试通过；5 项新增 Astra 测试包含在其中。价格以 2026-09-11 官方 Standard 公布值为参考；未采集的处理模式和供应商折扣不做推断。
