# Codex 会话归属与周期闪电汇总

## 供应商与来源

- 真实代理日志继续保留当时记录的供应商。
- 会话补录读取 `session_meta.model_provider`；某轮 `turn_context` 显式提供该字段时，以该轮声明为准。字段被明确清空时不沿用上一轮声明。
- `openai`、`yuanheng-switch-official` 的声明归入 `OpenAI Official`；通用别名 `custom`、`yuanheng` 以及无法识别的名称保持供应商未确认，不根据当前登录方式反推。
- 补录的 `data_source` 始终是 `codex_session`。列表同时显示供应商、会话声明标记和 Codex 会话日志来源；详情保留声明的原始标识与依据。
- 声明不等同于实际上游证明：兼容别名可在后续切换路由。此类记录只表示日志声明的归属，不会仅凭声明展示“账号计费”。现有代理/会话去重继续优先采用实际代理记录。

## 存量与汇总保护

Schema v19 为请求明细添加 `declared_provider`、`provider_attribution`，并在日汇总主键中保留 `data_source`。这样官方代理记录与归属官方的会话补录即使进入同一天汇总，也能在“重建 Codex 用量”时分别处理。

升级只把结构明确的 Codex rollout 游标标记为需重新读取，保留原来的行位置。首次同步为缺少归属的旧记录补齐声明时，必须同时匹配稳定请求 ID、模型、Token 数量和时间；不修改 Token、历史费用或已有明确归属，不重新插入已经处理过的记录。日汇总中已丢失原始日志依据的旧数据保留原状。

供应商统计的成功率、平均耗时只采用具备真实代理观测的记录，避免会话补录的占位 HTTP 200 / 0 毫秒影响指标。只有会话数据的供应商显示未提供性能数据。

## 周期汇总

用量页顶部增加大字号闪电总额及总请求、已计价、未计价数量：

- 默认最近 24 小时（滚动窗口）。
- 快捷切换今天、最近 7 天、最近 30 天；原日期选择器支持自定义和 14 天。
- 7 天和 30 天沿用现有本地日历口径，包含今天；卡片显示实际查询的起止日期和时间。
- 总额、趋势、模型/供应商统计和请求明细共用周期及筛选状态。
- 金额使用元衡平台报价的 ⚡ 估算，不将官方账号参考价值写成平台实际扣费；未定价请求明确标注未计入金额。

- 777 项前端测试通过，包括周期切换、筛选传递、未知费用不显示为免费、声明供应商与日志来源分开显示。
- 2287 项后端测试通过，2 项按项目配置忽略；新增覆盖声明优先级、旧记录补齐幂等、字段顺序不同的数据库升级、日汇总来源隔离及重建保护。
- TypeScript、生产目标 Clippy（禁止警告）、前端构建通过。
- Playwright 使用隔离演示数据，验证最近 24 小时切换到 7 天时金额/范围同步，并检查 1280px 和 390px 窗口布局。截图位于 `output/playwright/usage-summary-desktop.png` 和 `output/playwright/usage-summary-narrow.png`，未提交演示页面。
