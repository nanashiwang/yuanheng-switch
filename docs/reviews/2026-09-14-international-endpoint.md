# 默认线路迁移到 meta-api.vip

## 范围与不变量

- 登录、账号、分组、模型目录及模型请求默认使用 `https://meta-api.vip`。
- 官网、充值、声音克隆、更新公告、更新镜像和内置生图工具默认地址同步调整。
- 不变更 API 路径、模型名、分组、计费、令牌归属、更新公钥或协议转换。
- Codex 的本地回环地址不变。重新应用托管配置更新后台的上游地址。
- 不在启动时批量改写用户文件。旧 CN 配置标记需要重新应用，通过现有已验证的配置流程迁移；官方模式和外部供应商不自动切换。
- 旧 CN 仅用于识别托管凭据来源和回滚；不对失败请求自动跨域重放，不自动生成新凭据冒充旧组。
- 不读取真实用户凭据；本地测试使用临时配置目录、内存数据库和模拟请求。

- 使用精确 HTTPS 主机、443 端口及 API 路径白名单；拒绝相似域名、用户信息、查询参数和片段。
